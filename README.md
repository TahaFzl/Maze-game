# Smart Maze Game 🎮

## Overview
Maze Game is an interactive and dynamic maze game built with HTML, CSS, and JavaScript. Players can generate random mazes, navigate through them, and receive hints for the next steps to reach the goal. 

## Features
- Random maze generation.
- Pathfinding with visual hints.
- Touch and keyboard controls.
- Responsive design for a seamless experience on any device.
- Victory overlay with replay options.

## Demo
🎮 Play the game by opening `index.html` in your browser!

## How to Use
1. Clone the repository or download the files.
2. Open the `index.html` file in any web browser.
3. Use the arrow keys or swipe gestures to navigate the maze.
4. Click "New Maze" to generate a fresh maze or "Next 4 Steps" to view hints.

## File Structure
- `index.html`: The main HTML file.
- `styles.css`: Styling for the game.
- `scripts.js`: JavaScript logic for maze generation, rendering, and controls.

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
